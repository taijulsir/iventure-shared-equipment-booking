# iVenture Shared Equipment Booking — Frontend

Next.js (App Router) client application for iVenture Shared Equipment Booking.

## Getting Started

```bash
# Install dependencies
npm ci

# Configure environment (defaults to http://localhost:3000 API)
cp .env.example .env.local

# Run development server (listens on port 3001)
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser.

## Scripts

- `npm run dev`: Starts local Next.js dev server on port 3001
- `npm run build`: Production Next.js standalone build
- `npm run start`: Starts production standalone server on port 3001
- `npm run lint`: Runs ESLint
